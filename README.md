# חוות הבופאלו – אתר חדש

אתר סטטי (HTML/CSS/JS, בלי שלב בנייה) לחוות הבופאלו במושב בצרון. מחליף את האתר הישן ב-https://bufalo.co.il/.

האפיון המלא נמצא ב-[SPEC.md](SPEC.md).

## מבנה

| קובץ | תוכן |
|---|---|
| `index.html` | דף הבית |
| `visit.html` | ביקור בחווה: טעימות, קבוצות, סדנת מוצרלה, חנות, וידאו, הזמנה |
| `products.html` | קטלוג המוצרים, חלב הבופאלו, המעדנייה, איפה להשיג |
| `story.html` | הסיפור של המשפחה ועל הבופאלו |
| `recipes.html` | 8 מתכונים |
| `contact.html` | טלפונים, כתובת, שעות וטופס וואטסאפ |
| `accessibility.html` | הצהרת נגישות |
| `assets/css/style.css` | כל העיצוב (צבעים ופונטים מוגדרים למעלה ב-`:root`) |
| `assets/js/main.js` | תפריט, סטטוס ״פתוח עכשיו״, טופס וואטסאפ, אנימציות |
| `assets/img/` | תמונות (`products/` = תמונות אריזה לקטלוג) |

## עדכונים נפוצים

- **מספר הוואטסאפ להזמנות:** `WHATSAPP_NUMBER` בראש `assets/js/main.js`, ובקישורי `wa.me` בקבצי ה-HTML.
- **שעות פתיחה:** האובייקט `HOURS` ב-`assets/js/main.js` (לסטטוס ״פתוח עכשיו״), הטבלה `.hours` בדפים, ו-`openingHoursSpecification` ב-`index.html`.
- **החלפת תמונה:** שומרים קובץ חדש באותו שם ב-`assets/img/` (מומלץ עד 1600px רוחב, JPG באיכות 80).

הכותרת והפוטר זהים בכל הדפים. שינוי בתפריט צריך להיעשות בכל קבצי ה-HTML.

## תמונות שכדאי להחליף

- `making-*.jpg`: תמונות הכנת המוצרלה (2015, ברזולוציה נמוכה). מופיעות בסדנה ובשלבי ההכנה.
- `farm-mural.jpg`, `family.jpg`, `farm-store.jpg`: תמונות ישנות. כדאי לצלם מחדש את החווה, העדר והחנות.
- חסרות תמונות איכותיות של **הבופאלו עצמם** ושל **ארוחת הטעימות**.

## העלאה לאוויר

מדריך מלא, צעד אחר צעד, כולל חיבור הדומיין bufalo.co.il, נמצא ב-[DEPLOY.md](DEPLOY.md).

- `.nojekyll`: מבטל את העיבוד של Jekyll ב-GitHub Pages.
- התיקיות עם השמות בעברית (`מתכונים/`, `צור-קשר/` וכו') ו-`products_gallery/`, `product-catalog/`: הפניות מהכתובות של האתר הישן לעמודים החדשים, כדי לשמור על הדירוג בגוגל.
- `404.html`, `sitemap.xml`, `robots.txt`: נמצאים בשורש.

## מצב הדגמה (לא מופיע בגוגל)

כרגע האתר הוא הדגמה, ולכן הוא מוסתר ממנועי חיפוש בשני אופנים:
- תגית `<meta name="robots" content="noindex, nofollow">` בכל דף.
- הקובץ `_headers`, שבו Netlify מוסיף לכל קובץ את הכותרת `X-Robots-Tag: noindex`.

**כשהאתר עולה באופן רשמי:** מוחקים את `_headers` ואת תגיות ה-robots מהדפים הראשיים. בדפי ההפניה בתיקיות העבריות התגית נשארת.
